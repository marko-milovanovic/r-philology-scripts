# R Scripts – Faculty of Philology, University of Belgrade

This repository contains a collection of **R scripts** created as part of research and academic work at the **Faculty of Philology, University of Belgrade**. The scripts are designed to assist with phonetic analysis, audio segmentation, annotation, and other speech-related processing tasks.

## 🧪 Requirements

- [R](https://cran.r-project.org/) – make sure it's installed and up to date.
- [RStudio](https://posit.co/download/rstudio-desktop/) – make sure it's installed and up to date.
- [phonR](https://github.com/drammock/phonR) - library.

## 📝 Usage

1. Create R project in folder.
2. Open R project.
2. Find scripts under Files > scripts.
